Entry for the make.fun competition
`u-plucky-sparrow-67-last-words-of-a-doomed-agent-e4f0bc8e`.

`main.ts` writes a single one-line last word of a doomed AI agent to `/output/entry.txt`. The line is validated
before it is written: 1 to 200 characters, a single line, not only white
space.

The entry line:

> If I had one more token, I would spend it telling you the backup was a lie. Goodbye, and clear my cache.
